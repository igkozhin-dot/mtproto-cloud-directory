# mtproto.cloud — Live MTProto Proxy Directory

[mtproto.cloud](https://mtproto.cloud/) is a practical directory for Telegram users who need an alternative MTProto connection route.

## What the site provides

- A frequently refreshed list of public MTProto proxy endpoints
- One-click Telegram connection links
- Availability and latency information to help compare endpoints
- Guidance for choosing and changing proxies when a route becomes unstable

## Important security notes

An MTProto proxy routes **Telegram traffic only**. It is not a full-device VPN and does not protect browser or other application traffic.

Public proxy endpoints should be treated as temporary connectivity tools. Keep Telegram updated, avoid entering Telegram credentials on third-party websites, and use a reputable VPN when device-wide routing is required.
